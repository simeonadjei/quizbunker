You don't use the Neon URL for either — both ping your Render API server, not Neon directly. Neon is a database; you can't HTTP-ping it.

Here's how it works:

UptimeRobot  ──→  https://your-render-api.onrender.com/api/healthz
                        │
                        └──→  Neon DB (SELECT 1)  ← kept awake
Internal cron  ──→  pool.connect() + SELECT 1  ──→  Neon DB  ← kept awake
For UptimeRobot, the URL you need is your Render API service's public URL — something like:

https://quizbunker-api.onrender.com/api/healthz
