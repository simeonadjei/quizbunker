Can users log in and play without internet?

No — the app is fully server-dependent right now:

Login hits POST /auth/login on the API server to verify credentials and create a session. Without internet that request fails and the user can't get in.
Playing fetches questions from the server per session (POST /quiz-sessions, then GET /quiz-sessions/:id/question). No questions are cached locally.
The only thing that works offline is viewing pages that are already loaded in the browser tab (React router navigation), but any data fetch will fail with a network error.

To support offline play you'd need:

Persistent login — store a token/user record in localStorage so the app knows who the user is without a server round-trip
Question caching — use a Service Worker + Cache API (or IndexedDB) to cache downloaded question sets so they're playable without network
Session sync — queue completed quiz sessions locally and sync scores when internet returns
